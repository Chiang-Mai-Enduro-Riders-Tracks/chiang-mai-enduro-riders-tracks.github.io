Track editors

How to update a track. Every change gets a version number, date and name automatically.

← Back to tracks

Editors: . You need a free GitHub account that's been added to the site. Nothing to install. Everything happens on the GitHub website, on a phone or a computer.

1. Check a rider's recording first (optional)

Pick the track, then open the GPX a rider sent. Their ride shows in white, and parts more than 50 m off the current track turn red. Nothing is uploaded; this stays on your device.

2. Replace a track

  1. Sign in to GitHub, then tap Upload new GPX version
  2. Drop in the new GPX. Use exactly the same file name as the old one; that replaces it. Each track page shows its current file name under "Track editors".
  3. In the first box under the files, write one line about what changed, e.g. Reroute around new no off-road sign at km 12.
  4. If the change came from someone else's recording, write their name in the second (description) box: By: Somchai. The site then shows "Somchai (uploaded by you)". Otherwise your GitHub name is used.
  5. Click Commit changes. The site updates by itself in about 2 minutes, and the version goes up by one (v1 → v2).

Difficulty changed, so the file name changes too (e.g. 06-2of5-… → 06-3of5-…)? Delete the old file in the same folder, then upload the new one. Keep the same number at the start; the number is what links the versions together.

3. Change a description

  1. Sign in to GitHub, then tap Edit description
  2. Edit the text. Keep the dashed lines and the file name above each track. The site reads the description from there.
  3. Click Commit changes, with one line about what you changed.

4. Add a new track

  1. Upload the GPX named with the next number, e.g. 08-2of5-Doi-Saket-loop.gpx.
  2. Add its section to NOTES.txt in the same format as the others (Difficulty, Notes, Terrain, Length, Wet conditions, Up/downhills, Shaded, and Legal if needed).

5. Undo a mistake

Nothing is ever lost. Every old version stays in the GitHub history. Open the file on GitHub → History, download the older version, and upload it again as above.

The GitHub links above become active once the site's repository is set (repo in tracks/site.json).
